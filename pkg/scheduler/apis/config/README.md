# Scheduler Configuration API (`pkg/scheduler/apis/config`)

This package defines the configuration APIs (`KubeSchedulerConfiguration` and plugin arguments), scheme registration, version negotiation, defaulting, conversion, validation, and test fixtures for the Kubernetes Scheduler.

For an in-depth guide on the configuration architecture, dual-scheme design, latest defaulting helper, test fixtures (`testing/defaults`), and maintenance rules, see [AGENTS.md](AGENTS.md).
